方向 1：VS Code 风格

推荐 三栏布局 可收起面板 深色主题 专业感
方向 2：Ulysses 风格
极简主义，单栏编辑，心流优先
极简 单栏编辑 心流模式 无干扰
方向 3：Scrivener 风格
信息密集型，多级大纲，复杂项目管理
信息密集 多级大纲 Inspector 面板 复杂项目
方向 4：Notion 风格
块级编辑，灵活页面，嵌套组织
块编辑 灵活页面 嵌套组织 Wiki 风格
方向 5：Cursor 风格
AI 优先，行内生成，Chat 面板
AI 优先 行内生成 差异对比 Chat 面板
方向 6：混合风格
VS Code 架构 + Ulysses 极简，可切换密度
平衡 可切换密度 可收起面板 适应阶段
